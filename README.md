# «Альтик» бөбекжай-балабақшасы — лендинг

Next.js 15 · TypeScript · Tailwind CSS 4. Основной язык — казахский, светлая тема на всех устройствах.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production-сборка
npm start
```

## Фотографии и логотип

Положите файлы в `public/images` — они подхватятся автоматически при `npm run dev` / `npm run build`
(скрипт `scripts/detect-images.mjs` записывает их размеры в `lib/images.generated.json`):

| Файл | Где используется |
|---|---|
| `logo.png` (лучше с прозрачным фоном; также `.webp`/`.svg`) | шапка, главный экран, подвал |
| `main-page.jpg` | фото главного экрана (в органической форме) |
| `main-page2.jpg` | фото в разделе «Біз туралы» |
| любые другие (`01.jpg`, `02.jpg`, …) | галерея (6 в сетке + «Көбірек көрсету») |

Пока фото нет, на главном экране — векторная иллюстрация, а в галерее — ссылка на Instagram.

## Контакты, WhatsApp и документы

Все данные — в `lib/site.ts`:

- `whatsapp` — номер в формате `77001234567`. Пока пусто, кнопка WhatsApp не показывается.
- `documentsUrl` — ссылка на папку Google Drive. Пока пусто, вместо кнопки — приглашение написать в Instagram.
- `geo` — координаты для карты 2ГИС.

## Тексты и русская версия

Все тексты — в `lib/i18n/kk.ts`. Чтобы добавить русский язык, создайте `lib/i18n/ru.ts` с той же структурой
(тип `Dictionary`) и подключите его в `lib/i18n/index.ts`.

## Деплой на Vercel

1. Загрузите репозиторий на GitHub и импортируйте его в Vercel (Framework: Next.js, настройки по умолчанию).
2. Для своего домена задайте переменную окружения `NEXT_PUBLIC_SITE_URL` (например, `https://altik.kz`) —
   она используется в canonical, sitemap и Open Graph.
